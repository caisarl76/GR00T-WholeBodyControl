# D435i FOV 비교 오버레이 설명

이 그림은 RealSense D435i의 스트림 해상도별 시야(FOV)를 가장 넓은 뷰 위에 겹쳐 그린 것이다. 배경 사진은 실제 1280×720 RGB 캡처이고 축은 광축 기준 각도(탄젠트 스케일)다.

- 회색 점선: depth/IR 시야. 16:9 모드는 89.1°×57.9°로 이 카메라에서 가장 넓다. 이 영역에는 RGB 픽셀이 없다.
- 파란 실선: RGB 1280×720. RGB 최대 시야인 70.2°×43.1°다.
- 초록 일점쇄선: RGB 424×240. 69.9°×43.1°로 거의 전체 시야이고 USB2에서도 60fps가 나온다.
- 빨간 실선: RGB 640×480. 현재 GR00T-WBC와 LeRobot 카메라 서버의 기본값이며 55.6°×43.1°다. 펌웨어가 센서 가운데를 잘라내므로 붉게 칠한 좌우 영역(HD 기준 160px씩)이 버려진다. 오른쪽만 잘리는 것이 아니라 좌우 대칭이다.
- 노란 파선: 현재 640×480 영상 중 GR00T N1.7 VLA에 실제로 들어가는 범위. 입력 352×256, 토큰 88개, 50.7°×39.1°.
- 보라 파선: 16:9 모드(예: 640×360@60)를 쓸 때 VLA가 보는 범위. 입력 448×256, 토큰 112개, 64.5°×39.1°.

VLA는 영상의 짧은 변을 256px로 줄이고 가운데 약 90%를 자른 뒤 다시 256px로 맞춘다. 그래서 카메라 해상도를 아무리 높여도 모델이 받는 디테일은 약 230줄에서 멈춘다. 해상도보다 시야가 더 중요하다는 뜻이다. 640×480 대신 640×360@60(USB3)이나 424×240@60(USB2)을 쓰면 모델이 보는 수평 시야가 50.7°에서 약 64.5°로 27% 넓어진다.

다만 데이터 익스포터는 640×480 프레임만 받도록 고정돼 있고 기존 체크포인트도 640×480으로 학습됐다. 모드를 바꾸려면 익스포터 해상도 상수를 고치고 데이터를 다시 모아 재학습해야 한다.
